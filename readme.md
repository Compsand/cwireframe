# cwireframe

terminal wireframe rendering thingy made in c

currently it's just a cube but it can be changed fairly easily

press [w] a couple times to move the model into view

[w]/[s] to move model on the z axis, 
vim keys to move model the x/y axis, 
[r] to implode the model (it's supposed to be rotation but i implemented it badly), 
[q] to quit

will probably crash if you're not mega careful
